# Screenshots

The images the wiki shows on its `The menu` and `Debugging` pages. The wiki
repository serves its own copies (`.../wiki/OldRon1977/HHauto/images/...`);
this folder is where they come from, so a menu change can be re-shot against a
known set.

After re-shooting one, copy it into the wiki repository under `images/` with
the same file name -- the pages link it by that name.
